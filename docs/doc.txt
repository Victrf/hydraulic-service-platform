# 1. Verify the API Works

Open **Postman**, **Thunder Client**, or use **curl**.

### Create a user

Request:

```
POST http://localhost:3000/users
```

Body:

```json
{
  "name": "Admin",
  "email": "admin@test.com",
  "passwordHash": "123456",
  "role": "admin"
}
```

If everything is correct, you should receive something like:

```json
{
  "id": "uuid-value",
  "name": "Admin",
  "email": "admin@test.com",
  "passwordHash": "123456",
  "role": "admin",
  "createdAt": "2026-03-09T..."
}
```

---

### Fetch users

Request:

```
GET http://localhost:3000/users
```

Expected result:

```json
[
  {
    "id": "...",
    "name": "Admin",
    "email": "admin@test.com",
    "role": "admin"
  }
]
```

This confirms the full pipeline works:

```
Controller → Service → Prisma → PostgreSQL
```
