# Hydraulic Service Platform

A full-stack service management platform designed for the hydraulic engineering industry. The platform enables businesses, technicians, and customers to manage hydraulic equipment, service requests, products, maintenance records, and business operations from a unified system.

The project is being developed as a **cross-platform solution**, with the mobile application currently serving as the primary client while a web application is under active development using the same backend infrastructure.

## Architecture

```
hydraulic-service-platform/

apps/
├── api/          # Backend API
├── mobile/       # React Native Mobile App
└── web/          # React Web Application (In Progress)
```

The platform follows a monorepo architecture to simplify code sharing, maintenance, and deployment across multiple platforms.
